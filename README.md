# BMI Calculator - Oasis Infobyte Internship 

A simple and interactive BMI Calculator built using Python and Tkinter during my Python Programming Internship at **Oasis Infobyte**.

## 🚀 Features
- Input Height (in cm/m) and Weight (in kg)
- Calculates BMI instantly using formula: `BMI = weight / (height²)`
- Displays BMI Category:
    - Underweight: < 18.5
    - Normal: 18.5 - 24.9
    - Overweight: 25 - 29.9
    - Obesity: 30+
- Input validation for invalid/empty values
- Clean and user-friendly GUI with Tkinter
- Responsive layout

## 🛠️ Tech Stack
- **Language:** Python 3
- **GUI Library:** Tkinter (built-in)
- **IDE:** VS Code / PyCharm
